# JARVIS 7.1.8 — Universal Launcher and Project Executor

Adds a future-proof Windows application and project execution layer.

- Discovers installed Windows applications through Start Menu registrations.
- No hard-coded application list is required.
- Applications installed later can be discovered without a JARVIS update.
- Supports natural open, launch, start, run, and bring-up phrases.
- Adds registered project/script launching through data/projects.json.
- Supports direct file/folder paths.
- Existing router commands remain available.
- Project execution is limited to projects explicitly registered in data/projects.json.
