# JARVIS 8.0.0

Major native migration release.

Included:
- Windows-native C#/.NET 8 JARVIS runtime scaffold
- self-contained win-x64 publish configuration
- JARVIS Arduino USB/Serial library
- JARVIS Serial Protocol 1
- preservation of the existing Python V8 runtime during migration

Approval-gated:
- replacing the active Python runtime
- installing/starting a new background service
- automatic phone integration
- automatic external-device control

This release does not delete or overwrite the existing V8 runtime.
