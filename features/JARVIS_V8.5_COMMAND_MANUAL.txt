FEATURE BEHAVIOR
1 Universal Command Router: normalizes aliases and routes only registered capabilities.
2 System Intelligence: read-only OS, CPU/RAM/disk/battery/uptime. Some metrics are optional/platform-specific.
3 Smart App Launcher: allowlisted app/site targets only; no arbitrary shell commands.
4 Persistent Memory: local opt-in facts; view and forget supported; never store passwords, API keys, OTPs, or private keys.
5 Offline Brain: transparent fallback; general AI requires an installed local model or reachable provider.
6 File Intelligence: searches selected user folders, reports paths only; no deletion, edits, or upload.
7 Focus Mode: local timer; Ctrl+C cancels in terminal mode.
8 Network Watch: basic DNS check; not a security scanner.
9 Hardware Simulator: virtual state only; no GPIO/hardware actuation.
10 Portable Profile: local host/app info; no fingerprint upload.

REQUIREMENTS
Windows 10/11; user-level permissions; Python version and optional packages will be specified in the installable release.
Network required for web launch and DNS check. AI requires configured provider/model.
Do not assume USB autorun. Launch manually unless the user explicitly configures an approved startup method.
Safety: feature installation must verify SHA-256, back up changed paths, reject path traversal, avoid overwriting user data, and require confirmation for side effects.
